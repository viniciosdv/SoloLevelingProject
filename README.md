## 💻 Sobre o Projeto

Este projeto é uma landing page imersiva e interativa inspirada no universo de **Solo Leveling**. Desenvolvido com foco em performance e design futurista/cyberpunk, ele simula a interface do "Sistema" de evolução de caçadores, contando com transições dinâmicas baseadas em rolagem, efeitos visuais de glitch e um exército de sombras perfeitamente integrado à interface.

---

## ✨ Tecnologias Utilizadas

A estrutura foi construída utilizando ferramentas modernas da Web:

*   **HTML5 & CSS3** — Estrutura semântica e estilização avançada com variáveis CSS, Flexbox e Grid.
*   **JavaScript (ES6+)** — Lógica interativa, sistema de partículas e controle de estado dinâmico.
*   **GSAP (GreenSock Animation Platform) + ScrollTrigger** — Animações fluidas e sincronização de seções baseadas no scroll.
*   **Fontes Personalizadas** — *Barlow Condensed*, *Orbitron* e *Space Grotesk*.

---

## 🚀 Funcionalidades

*   ⚡ **Loader de Inicialização:** Simulação de sincronização de dados do portal antes de carregar a página.
*   👥 **Múltiplos Agentes/Personagens:** Alterne entre os caçadores (Sung Jinwoo, Cha Hae-In, Choi Jong-In e o Exército das Sombras) com temas de cores dinâmicos.
*   🌌 **Efeitos Visuais Imersivos:** Fundo com efeito de grade perspectiva 3D, partículas flutuantes e transições elétricas customizadas.
*   📱 **Design Responsivo:** Adaptado para diferentes tamanhos de tela e dispositivos.
