## 📌 Sobre o Projeto

O **SoloLevelingProject** é uma landing page interativa de alta performance desenvolvida para simular a interface do "Sistema" de evolução de caçadores. O projeto explora transições fluidas baseadas em rolagem (*scroll*), efeitos visuais dinâmicos de iluminação e cibernéticos, além de um exército de sombras perfeitamente integrado à interface.

---

## ✨ Principais Funcionalidades

* ⚡ **Loader de Inicialização:** Tela de carregamento com sincronização de dados simulada antes de liberar o acesso ao portal.
* 👥 **Múltiplos Agentes & Temas Dinâmicos:** Alterne entre diferentes caçadores (Sung Jinwoo, Cha Hae-In, Choi Jong-In e o Exército das Sombras), onde cada um possui sua própria identidade visual e paleta de cores.
* 🌌 **Efeitos Visuais Avançados:** 
  * Fundo com grade perspectiva 3D interativa que reage ao movimento do cursor do mouse.
  * Sistema de partículas fluidas em tempo real utilizando HTML5 Canvas.
  * Efeito de glitch cibernético nos títulos ao trocar de personagem.
* 📱 **Design Totalmente Responsivo:** Otimizado para se adaptar perfeitamente a diferentes tamanhos de tela e dispositivos.

---

## 🛠️ Tecnologias e Ferramentas

O projeto foi construído utilizando tecnologias modernas da web sem o uso de frameworks pesados, focando em velocidade e animações fluidas:

* **HTML5 & CSS3** (Variáveis CSS, Flexbox, Grid e máscaras avançadas)
* **JavaScript Moderno (ES6+)**
* **GSAP (GreenSock Animation Platform)** + **ScrollTrigger** (Para animações e controle de scroll de alta precisão)
* **Fontes:** *Barlow Condensed*, *Orbitron* e *Space Grotesk*
